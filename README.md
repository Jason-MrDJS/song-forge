## . Song Forge v1.0 — 歌曲流水线总控

**核心定位**：把「写歌」变成一条可自动闭环的生产流水线。

**价值亮点**

- 串联三大专业技能：**lyric-writer（歌词创作）→ bmz（歌词质检）→ lyria-music-producer（双槽 prompt 编译）**。
- 写初稿 → 双评分质检 → 未达标自动回炉改写 → 达标后才编译 prompt，形成闭环。
- 用 **单一真相文件 TrackSpec.md** 传递数据，各阶段只写自己区段，无格式断层。
- 内置 Revision.Directive 桥接件、伪控制标签强制翻译层、回环终止与反循环保护；支持中英双语分流。

> 一句话：从一句灵感到一个能直接丢进 Suno / Lyria 的提示词，全程托管。
